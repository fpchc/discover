# 工具代理与三级暴露规范

## 适用场景

- 修改工具目录、命名空间、检索、描述、激活或分发
- 调整工具并发、超时、截断、错误结果或参考文档读取
- 排查工具重名、选错工具、参数约束未暴露或上下文过大

## 不适用场景

- MCP 连接协议、脚本进程生命周期或 Agent 阶段编排

## 职责边界与权威来源

ToolBroker 负责统一目录、暴露集合和调用分发；不负责技能选择、业务策略或底层实现。MCP 见 `mcp-integration-spec.md`，脚本见 `script-execution-spec.md`，装配见 `skill-assembly-spec.md`。

## 1. 三级暴露

```text
Tier 0：常驻元工具
Tier 1：技能核心工具、脚本和门禁校验器
Tier 2：其余已发现工具，先检索和描述，再加入当前会话暴露集合
```

目标是限制每次 LLM 请求中的工具 Schema 体积，同时保持长尾工具可发现。禁止把全部 MCP 工具无条件注入上下文。

Tier 0 至少提供：

- `search_tools`：按名称与说明检索目录，不返回完整参数 Schema。
- `describe_tool`：返回完整描述符，并把目标加入会话暴露集合。
- `read_reference`：安全读取当前技能声明的参考文档。

## 2. 命名空间

- MCP：`<server>.<tool>`。
- Script：`<agent>.<skill>.script.<tool>`。
- 进入模型前把不兼容的命名片段做确定性规范化。
- 限定名是唯一执行键；短名只用于展示和检索，不得直接分发。

命名规则集中实现，禁止各适配器自行拼接。

## 3. ToolDescriptor

统一描述符使用 Pydantic，包含：

- 限定名、短名、命名空间、来源、tier
- 描述、JSON 参数约束、超时、副作用
- 来源引用和必要的脚本声明
- 幂等、可重试、最大尝试数、指纹忽略字段、阶段标签

描述符在装配 / 激活阶段构建，运行时只读。具体客户端或进程句柄不得进入描述符。

## 4. 目录与会话状态

- 平台启动时注册 Tier 0。
- 技能激活时加入 Tier 1。
- MCP 工具发现后加入 Tier 2。
- `describe_tool` 只修改当前会话暴露集合，不改变全局目录。
- 会话结束时回收暴露集合和已加载文档记录。

禁止使用模块级可变 dict/list 共享会话目录。

## 5. 分发边界

Broker 根据描述符来源分发：

- META：本地元工具处理；
- MCP：交 MCP Manager / Client；
- SCRIPT：交脚本执行器。

Broker 不实现远程协议、不拉起脚本、不决定业务重试。所有成功和失败统一返回 `ToolResult`，不得把底层异常直接抛给模型。

## 6. 并发、超时和副作用

- 批量调用同时受全局信号量与单服务信号量限制。
- 结果顺序必须与输入可关联；单个失败不得导致整批丢失。
- 超时、取消、参数错误和服务错误转换为统一分类。
- 有副作用工具按策略串行化或禁止自动重试；幂等声明不可信时取保守策略。

## 7. 输出截断

进入模型上下文的工具结果必须按配置截断，并返回：原始长度、是否截断、必要时的完整结果引用。

- 优先保留可操作的摘要和结构化关键字段。
- 不在 event loop 中同步写完整日志。
- 完整结果存储失败不得伪装为已保存。
- 错误消息同样需要长度限制和脱敏。

## 8. 元工具安全

### search_tools

仅检索当前会话允许访问的目录；限制返回数量，输出名称、来源和短说明。

### describe_tool

目标必须是合法限定名。不存在时返回相近候选和下一步建议，不抛裸异常。

### read_reference

- 只允许当前技能 `references/` 下的相对路径；拒绝绝对路径、`..` 和越界解析。
- 支持按标题提取章节；结果按上下文预算截断。
- 已加载文档返回确定性状态，避免重复占用上下文。

## 9. ToolResult

失败结果至少包含调用 ID、工具名、错误类别、面向模型的建议和耗时；成功结果包含内容与截断标志。错误建议必须具体可执行，禁止只有“失败”或裸异常字符串。

## 10. 本规范专属检查

- [ ] 模型只收到 Tier 0、Tier 1 与已显式展开的 Tier 2
- [ ] 限定名唯一且集中生成，短名未用于直接分发
- [ ] Broker 未承担 MCP、脚本或业务策略职责
- [ ] 批量调用受双层并发、取消和副作用策略控制
- [ ] read_reference 无路径穿越，所有结果已截断和脱敏
