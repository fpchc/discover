# MCP 接入与能力抽象规范

## 适用场景

- 新增、更换或排查 MCP 服务
- 修改 MCP 注册表、capability、failover 或 fallback
- 调整连接生命周期、工具发现、认证、超时和并发

## 不适用场景

- Skill 清单字段设计、工具三级暴露或具体业务数据规则

## 职责边界与权威来源

本文件定义稳定的 MCP 客户端与能力抽象契约。当前服务、端点和启用状态以 MCP 注册表为准；当前架构以 `.ai/ARCHITECTURE.md` 为准，路径以 `.ai/MODULE_MAP.md` 为准，不在本文件维护服务清单。

## 1. 定位

平台是 MCP 客户端。具体服务可运行在远端或独立本地进程，但平台业务进程不内嵌其业务实现。

当前传输契约为 Streamable HTTP。所有网络请求经 `httpx.AsyncClient`；认证令牌只保存环境变量名，真实值按需解析。

## 2. 注册表

服务条目结构化声明：

| 字段 | 语义 |
|---|---|
| `id` | 平台内唯一服务 ID |
| `transport` | 当前固定 `streamable_http` |
| `base_url` | 配置值，可使用环境变量占位 |
| `auth` | 认证类型与 token 环境变量名 |
| `per_session` | 会话独占或共享连接 |
| `handshake_timeout_seconds` | 握手超时 |
| `call_timeout_seconds` | 单调用超时 |
| `concurrency_limit` | 单服务并发限制 |
| `enabled` | 是否参与装配和连接 |

`enabled: false` 表示保留注册但不参与运行，不等于删除。仓库只提交样例配置，不提交真实端点密钥。

## 3. 能力抽象

Skill 对可互换提供方只声明 capability，注册表决定实际服务：

- `servers`：有序候选列表；所有 ID 必须已注册。
- `strategy=failover`：按顺序尝试，首个可用者生效。
- `strategy=all`：全部候选独立激活，不做主备和 fallback。
- `fallback`：只允许一级降级，不能指向自身，也不能形成链或环。

新增、删除或替换等价提供方应只修改注册表，不修改业务 Skill 和 Runtime。

## 4. 客户端协议

- 初始化、工具列表和工具调用均使用统一 JSON-RPC / MCP 语义。
- 会话 ID、协议版本和必要响应头由 MCP 客户端封装。
- 支持普通 JSON 与流式响应时，在客户端边界归一为稳定结果。
- HTTP 成功不代表协议成功；必须继续校验响应结构与错误对象。
- 工具参数与结果保持 JSON 可序列化，不向上层暴露 httpx 响应对象。

## 5. 生命周期

- 共享服务按引用计数复用连接；会话态服务按会话隔离。
- acquire / release 必须异常安全，失败初始化不得留下半激活状态。
- 应用关闭时释放所有客户端；空闲回收不得关闭仍被引用的服务。
- 装配层只生成候选计划，运行时负责连接和降级，Manager 负责客户端生命周期。

## 6. 工具发现

连接成功后调用 list-tools，将结果转换为统一 `ToolDescriptor`。服务返回的名称、说明和参数约束视为外部输入，必须校验；隐藏的泛化分发工具不得重复暴露给模型。

工具限定名由服务命名空间和工具短名组成，避免跨服务重名。具体命名规则由 `tool-broker-spec.md` 统一维护。

## 7. 调用、并发与超时

- 每次调用同时受全局工具并发和单服务并发限制。
- 超时使用服务配置；调用取消必须向下传播。
- failover 只发生在能力候选之间，不把业务失败误判为服务不可用。
- 对有副作用或非幂等调用不得自动跨服务重放。

## 8. 错误与降级

统一分类：配置、认证、握手、超时、限流、协议、参数、服务端和连接错误。

- required 服务或能力全部失败：终止当前激活或阶段。
- optional 服务或能力失败：记录降级并继续。
- fallback 命中：明确标记实际能力已降级。
- 错误结果必须包含可执行建议，但不得泄露 token、完整请求体或敏感响应。

## 9. 本规范专属检查

- [ ] 服务状态只存在于注册表，没有复制到长期规范
- [ ] capability 引用合法，fallback 仅一级且无环
- [ ] 客户端生命周期、引用计数与异常释放完整
- [ ] 工具发现结果已校验并转换为统一描述符
- [ ] 调用受双层并发、超时和取消控制，错误已脱敏
