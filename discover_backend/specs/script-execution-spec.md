# 白名单脚本执行规范

## 适用场景

- 修改技能脚本声明、脚本执行器、标准流协议或产物扫描
- 调整脚本超时、终止、环境变量、输出限制和失败处理
- 评审脚本依赖与安全边界

## 不适用场景

- 任意用户代码执行、通用 Shell 工具或 MCP 服务实现

## 职责边界与权威来源

本文件定义可信仓库内白名单脚本的执行契约。当前实现采用宿主子进程；若安全模型变化，应先形成新的架构决策，而不是在本规范中并存多套流程。脚本声明字段见 `agent-package-spec.md`。

## 1. 安全模型

- 只执行当前激活 Skill 清单中声明且加载期校验通过的脚本。
- 不向模型暴露任意命令、Shell、路径或解释器参数。
- 脚本路径必须解析在当前技能 `scripts/` 下，禁止绝对路径、目录穿越和符号链接越界。
- 用户输入只能作为结构化 stdin 数据，不得拼接进命令行或 Shell 字符串。
- 启动子进程使用参数数组并禁用 shell 模式。

## 2. 标准流契约

| 通道 | 约束 |
|---|---|
| stdin | 单次写入 UTF-8 JSON，写完关闭 |
| stdout | 结果通道，优先输出单个 JSON 文档 |
| stderr | 诊断通道，不作为业务成功结果 |
| exit code | `0` 表示执行完成；非零表示失败 |

平台必须同时考虑退出码与输出解析。退出码为 0 但结果结构非法时仍视为协议错误；非零退出不得因 stdout 存在内容而误判成功。

## 3. 输入校验

- 有 `schema_path` 时，在启动进程前校验参数。
- Schema 错误返回参数非法和可执行建议，不启动脚本。
- 平台注入字段与用户字段分离，禁止用户覆盖工作区、账号、会话、历史等受控值。
- 输入大小受配置限制，防止一次性写入失控。

## 4. 环境变量

子进程只接收最小环境：

- 平台运行所需的基础变量；
- Agent `env_whitelist` 声明且实际允许的变量；
- 平台生成的工作区、输入输出或历史契约变量。

不得把完整 `os.environ` 无过滤透传。脚本只读取平台注入的路径，不硬编码机器绝对路径。密钥不得写入 stdout、stderr 或产物。

## 5. 生命周期与终止

- 启动、stdin 写入、stdout/stderr 读取和进程等待全部异步管理。
- stdout 与 stderr 并发排空，避免管道缓冲互相阻塞。
- 超时或取消时先 terminate，等待配置化宽限期，再 kill。
- 所有异常路径都必须等待或回收子进程，不遗留孤儿进程。
- 重试由上层策略决定；有副作用脚本默认不自动重试。

## 6. 输出限制

- stdout、stderr 和面向模型的结果分别按配置限流。
- 超限时保留可诊断部分并显式标记截断，不静默丢失。
- JSON 结果应先在安全预算内完成解析，再生成精简上下文；不得依赖截断后的 JSON 继续执行。
- stderr 只回传必要尾部并脱敏。

## 7. 副作用与产物

- `side_effect` 必须与真实行为一致；默认只读。
- 写文件脚本只能写入平台分配的工作区或产物目录。
- 执行前后由平台扫描差异并登记新产物；脚本不得自行伪造外部下载 URL。
- 产物路径归一化后必须仍位于允许目录，下载权限由平台校验。
- 历史存储由平台管理；`history_store` 脚本接收结构化历史并保持纯计算。

## 8. 依赖约束

脚本依赖必须在项目依赖中预先声明并随部署安装。禁止脚本运行时执行 pip install、下载可执行文件或访问未声明网络服务。重依赖或需要独立生命周期的能力优先实现为 MCP 服务。

## 9. 错误结果

统一区分：声明非法、输入校验、启动失败、超时、取消、非零退出、输出超限、协议解析和产物越界。错误结果必须包含面向模型的下一步建议，并对路径、密钥和输入内容脱敏。

## 10. 本规范专属检查

- [ ] 只执行清单白名单脚本，路径解析未越界
- [ ] 用户输入未进入命令字符串，子进程未启用 shell
- [ ] stdout / stderr 并发排空，超时执行 terminate → kill
- [ ] 环境变量最小化，输出和错误均限流脱敏
- [ ] 副作用、重试、产物与历史契约一致
