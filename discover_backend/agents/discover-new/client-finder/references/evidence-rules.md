# 证据规则（证据等级 + 独立性 + 动态补搜）

数据源由平台装配的数据能力提供（企业专有数据能力 + 联网搜索）。本文档定义证据的等级、独立性判定、关键字段的证据门槛与动态补搜条件。凡信息缺失一律「尽力采集 + 显式标注（未检索到）」，不得编造。

## 一、证据等级

| 等级 | 来源 | 说明 |
|---|---|---|
| L0 | 官方工商登记（注册资本 / 成立日期 / 地址 / 状态 / 经营范围） | 权威，单条即达标 |
| L1 | 企业官网 / 年报 / 招股书 / 上市公告 | 一手自述 |
| L2 | 权威媒体 / 研报 / 行业报告 | 二手可信 |
| L3 | 一般新闻 / 招聘 / 招标 / 舆情 | 信号级 |
| L4 | AI 推断 | 非证据，必须显式标「推断」 |

## 二、独立性判断

两条来源若**同源**（如都转载自同一公告 / 同一新闻稿 / 同一来源转载）算 **1 条独立来源**。
独立来源 = 不同机构、不同渠道、不同时间独立产出的证据。机械堆两条同源内容不构成交叉验证。

## 三、关键字段证据门槛

| 字段 | 门槛 | 不达标时 |
|---|---|---|
| 注册资本 / 成立日期 / 地址 | L0 工商，1 条即达标 | 「未检索到」 |
| 官网 / 电话 / 邮箱 | L0 或 L1，1 条即达标 | 「未检索到」 |
| 主营业务 | L0 经营范围 + L1 官网，≥1 条 L0 或 ≥2 条独立 | 「未检索到」 |
| 营收规模 | 上市公司 L1 财报；非上市无公开数据 | 按注册资本档估算，标「推断」 |
| 是否上市 | L0 / L1，1 条即达标 | 「非上市」或「未检索到」 |
| 行业 | L0 / L1，≥1 条 | 标「推断」 |
| 企业规模 | 参保人数（L0）；否则按注册资本档 | 标「推断」 |

## 四、首轮合并搜索 + 定向补搜

**首轮（合并搜索词，减少轮次）**：每企首轮 1-2 个并发搜索词覆盖多数字段，不再逐字段单搜：

- 词 A（工商+主营+规模）：`{公司名} 工商 注册资本 成立 主营 经营范围 规模`
- 词 B（触达+官网）：`{公司名} 官网 电话 邮箱 董事长 总经理`

**定向补搜（仅补缺项）**：首轮后逐字段扫描，缺证据的字段再定向补搜，停止条件 = 字段达标或相关通道穷尽：

| 缺失字段 | 补搜词 |
|---|---|
| 注册资本 / 成立 / 地址 | `{公司名} 工商 注册资本` |
| 主营 / 产品 | `{公司名} 主营 产品 经营范围` |
| 营收 / 财务 | `{公司名} 营收 年报 财报` |
| 决策人 | `{公司名} 董事长 总经理 高管` |
| 风险 | `{公司名} 失信 破产 处罚` |

穷尽后仍未检索到 → 显式标「未检索到」，不静默编造。

## 五、事实断言约束

- 关键结论标注来源；单源断言必须标注来源（如「据官网声称」）。
- 推断性结论用「推断 / 可能 / 估计」。
- 动态信号须带日期，超 6 个月标注「可能已过时」。
