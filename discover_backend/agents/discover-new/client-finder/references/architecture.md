# 电子信息产业链四层架构

## 概述

电子信息产业链覆盖从原材料到终端系统的完整价值链条，划分为四个层级。本架构定义用于客户发现过程中的产业链定位推断、上下游关系识别和行业分类匹配。

## 四层架构总览

```
┌─────────────────────────────────────────────────────────────────────────┐
│  L1  硬件系统                                                            │
│  ICT设备 | 汽车及轨道交通 | 消费电子 | 电力电源 | 医疗电子 | 工业控制 | 云服务商 | 安防 │
├─────────────────────────────────────────────────────────────────────────┤
│  L2  IC/模组/元器件                                                      │
│  处理器 | 控制器 | 射频/微波 | 功率器件 | 存储器 | 网络IO芯片 | 光模块/器件          │
│  显示模组 | 传感 | 摄像模组 | 生物 | 雷达 | 连接器 | 被动元件                    │
├─────────────────────────────────────────────────────────────────────────┤
│  L3  电子制造                                                            │
│  晶圆制造 | 封装 | 基板/PCB/PCBA | 整装                                   │
├─────────────────────────────────────────────────────────────────────────┤
│  L4  电子材料 / 电子设备 / 工具软件                                        │
│  组装材料 | 导热材料 | 板材/基材 | 功能材料 | 化学材料                           │
│  检测分析 | 制造设备 | 环境设备 | 测试设备                                      │
│  仿真软件 | 控制软件 | 管理软件 | 设计软件                                      │
└─────────────────────────────────────────────────────────────────────────┘
```

**价值流向**：L4 → L3 → L2 → L1（材料→制造→元器件→系统，自下而上）

## L1：硬件系统

终端产品和系统集成商，是产业链的最上层。直接面向最终用户和应用场景。

| 子类 | 典型产品/应用 | 典型企业类型 |
|------|-------------|-------------|
| **ICT设备** | 服务器、交换机、路由器、基站、光传输设备、数据中心 | 通信设备商、网络设备商、数据中心运营商 |
| **汽车及轨道交通** | 整车、域控制器、T-Box、ADAS、高铁信号系统 | 整车厂、Tier1供应商、轨道交通设备商 |
| **消费电子** | 智能手机、平板、笔记本、可穿戴、智能家居 | 品牌厂商、ODM/OEM代工厂 |
| **电力电源** | 光伏逆变器、储能系统、UPS、充电桩、变频器 | 电力设备商、新能源设备商 |
| **医疗电子** | CT/MRI、监护仪、超声、体外诊断、植入器械 | 医疗器械商 |
| **工业控制** | PLC、DCS、工业机器人、伺服驱动、仪器仪表 | 自动化设备商、仪器仪表商 |
| **云服务商** | 云计算平台、CDN、IDC | 云服务提供商 |
| **安防** | 视频监控、门禁、报警、消防电子 | 安防设备商 |

## L2：IC/模组/元器件

电子系统的核心功能单元，是硬件系统的组成部分。

| 子类 | 典型产品 | 说明 |
|------|---------|------|
| **处理器** | CPU、GPU、FPGA、SoC、AP、MCU、DSP | 通用/专用计算核心 |
| **控制器** | 存储控制器、显示驱动、触控IC、电源管理IC、接口芯片 | 系统控制和接口管理 |
| **射频/微波** | PA、LNA、滤波器、混频器、天线、射频前端模组 | 无线通信核心 |
| **功率器件** | MOSFET、IGBT、SiC/GaN器件、功率模块 | 电能变换与控制 |
| **存储器** | DRAM、NAND Flash、NOR Flash、EEPROM | 数据存储 |
| **网络IO芯片** | 以太网PHY、交换芯片、SerDes、PCIe桥片 | 数据通信接口 |
| **光模块/器件** | 光收发模块、光放大器、WDM器件、光芯片 | 光通信核心 |
| **显示模组** | LCD面板、OLED、MiniLED、MicroLED、触摸屏 | 显示交互 |
| **传感** | MEMS传感器、图像传感器、温度/压力/气体传感器、激光雷达 | 物理量感知 |
| **摄像模组** | 手机摄像模组、车载摄像模组、工业相机 | 图像采集 |
| **生物** | 生物芯片、微流控、生物传感器 | 生物检测 |
| **雷达** | 毫米波雷达、激光雷达、超声波雷达 | 探测与感知 |
| **连接器** | 高速背板连接器、射频连接器、电源连接器、FPC连接器、板对板连接器 | 信号/电源互连 |
| **被动元件** | MLCC电容、电阻、电感、晶振、滤波器 | 基础电子元件 |

## L3：电子制造

将材料和元器件加工、组装为可用的电路模块或整机。

| 子类 | 说明 | 典型工艺 |
|------|------|---------|
| **晶圆制造** | 半导体晶圆加工（Foundry） | CMOS、SiGe、GaAs、SiC、GaN工艺 |
| **封装** | 芯片封装与测试（OSAT） | BGA、CSP、SiP、3D封装、Flip-Chip、WLCSP |
| **基板/PCB/PCBA** | 印制电路板制造、SMT贴片、组装 | HDI、FPC、刚挠结合、IC载板 |
| **整装** | 终端产品组装与测试 | 整机装配、系统集成、老化测试 |

## 层级上下游关系

### 核心规则

**规则 1：直接下游**
每个层级的直接客户是该层级的上方一层：
- L4 的直接下游是 L3（材料→制造，设备→制造，软件→制造/L2设计）
- L3 的直接下游是 L2（封装→IC，PCB→IC/模组，整装→系统）
- L2 的直接下游是 L1（元器件→硬件系统）
- L1 的直接下游是最终用户/应用场景

**规则 2：间接下游**
可能存在跨层级的间接客户关系：
- L4 化学材料 → L2 元器件（功能材料直接用于芯片制造）→ 间接
- L3 晶圆制造/封装 → L1 硬件系统（IDM模式）→ 跨层直达
- L2 连接器 → 同时供货给 L3（PCB组装）和 L1（整机）

**规则 3：同层协作**
同层级企业之间存在横向配套关系，但不是"客户"关系：
- L2 的处理器厂商和存储器厂商共同服务于 L1 的整机厂商
- L4 的材料商和设备商共同服务于 L3 的制造商

### 典型上下游对应表

| 你的产品（所在层级） | 直接客户（下游层级） | 典型场景 |
|-------------------|------------------|----------|
| L4 电子材料 | L3 电子制造 | 材料商→PCB厂、封装厂、组装厂 |
| L4 电子设备 | L3 电子制造 | 设备商→晶圆厂、封装厂、PCB厂、组装线 |
| L4 工具软件 | L2 IC设计、L3 制造 | EDA商→IC设计公司、仿真软件商→PCB/封装/系统设计 |
| L3 晶圆制造 | L2 IC/元器件 | Foundry→IC设计公司（Fabless）、IDM |
| L3 封装 | L2 IC/元器件 | OSAT→IC设计公司 |
| L3 PCB/PCBA | L2 模组、L1 系统 | PCB厂→模组厂、整机厂 |
| L3 整装 | L1 硬件系统 | 代工厂→品牌厂商 |
| L2 IC/元器件 | L1 硬件系统 | 芯片商→整机厂商、模组商→整机厂商 |
| L2 连接器/被动元件 | L1 硬件系统、L3 PCBA | 连接器商→整机厂、PCB组装厂 |
| L1 硬件系统 | 最终用户 | 设备商→运营商、企业、消费者 |

## 层级推断规则

当用户提供产品描述后，按以下规则推断产品所属层级和潜在客户层级：

1. **关键词匹配**：将产品关键词与各层级的子类关键字比对，确定产品所属层级
2. **直接客户推断**：产品所属层级的上一层级（或上两个层级）即为直接客户所在层级
3. **应用场景扩展**：若产品覆盖多个应用场景，按照"一个场景→一组客户"的规则分别推断
4. **跨层特殊情况**：
   - 连接器/被动元件等基础元器件（L2）→ 客户可能是 L3（PCBA厂商）或 L1（整机厂直接采购）
   - 功能材料（L4）→ 若直接用于芯片制造，客户可能是 L2（芯片厂）而非 L3
   - 工具软件（L4）→ 若用于芯片设计，客户是 L2（IC设计公司）

### 推断示例

| 用户输入 | 推断产品层级 | 推断客户层级 | 推理过程 |
|---------|:----------:|:----------:|----------|
| "高速背板连接器" | L2 连接器 | L1 ICT设备/服务器 | 连接器→通信设备/服务器/交换机 |
| "PCB" | L3 基板/PCB/PCBA | L2 模组、L1 系统 | PCB→模组厂、整机厂（两类客户） |
| "导热硅脂" | L4 导热材料 | L3 封装/整装 | 导热材料→芯片封装散热、整机散热 |
| "车规MCU" | L2 处理器/MCU | L1 汽车及轨道交通 | MCU→Tier1/整车厂 |
| "SMT贴片" | L3 PCBA | L2 模组、L1 系统 | PCBA代工→模组/整机厂商 |
| "光刻胶" | L4 功能材料 | L3 晶圆制造 | 光刻胶→晶圆厂 |
| "EDA软件" | L4 设计软件 | L2 IC设计、L3 PCB设计 | EDA→IC设计公司、PCB设计 |
