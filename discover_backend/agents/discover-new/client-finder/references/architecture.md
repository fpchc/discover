# 电子信息产业链四层架构（层级推断用）

用于客户发现中的产业链定位推断、上下游关系识别。价值流向：L4 → L3 → L2 → L1（材料→制造→元器件→系统，自下而上）。

## 一、四层概览

| 层级 | 名称 | 子类 |
|---|---|---|
| L1 | 硬件系统 | ICT设备 / 汽车及轨道交通 / 消费电子 / 电力电源 / 医疗电子 / 工业控制 / 云服务商 / 安防 |
| L2 | IC/模组/元器件 | 处理器 / 控制器 / 射频微波 / 功率器件 / 存储器 / 网络IO芯片 / 光模块 / 显示模组 / 传感 / 摄像模组 / 生物 / 雷达 / 连接器 / 被动元件 |
| L3 | 电子制造 | 晶圆制造 / 封装 / 基板PCB/PCBA / 整装 |
| L4 | 材料·设备·软件 | 组装材料 / 导热材料 / 板材基材 / 功能材料 / 化学材料；检测分析 / 制造设备 / 环境设备 / 测试设备；仿真 / 控制 / 管理 / 设计软件 |

## 二、上下游关系

**直接下游**：每个层级的直接客户是上方一层——
- L4 → L3（材料/设备/软件 → 制造）
- L3 → L2（封装 → IC；PCB → IC/模组；整装 → 系统）
- L2 → L1（元器件 → 硬件系统）
- L1 → 最终用户

**跨层特殊情况**：
- 连接器 / 被动元件（L2）→ 客户可能是 L3（PCBA厂）或 L1（整机厂直接采购）
- 功能材料（L4）→ 若直接用于芯片制造，客户可能是 L2（芯片厂）
- 工具软件（L4）→ 用于芯片设计时客户是 L2（IC设计公司）

## 三、产品 → 下游层级推断表

| 用户产品（层级） | 直接客户（下游） | 典型场景 |
|---|---|---|
| L4 电子材料 | L3 电子制造 | 材料商 → PCB厂 / 封装厂 / 组装厂 |
| L4 电子设备 | L3 电子制造 | 设备商 → 晶圆厂 / 封装厂 / PCB厂 / 组装线 |
| L4 工具软件 | L2 IC设计、L3 制造 | EDA → IC设计公司；仿真 → PCB/封装/系统设计 |
| L3 晶圆制造 | L2 IC/元器件 | Foundry → Fabless / IDM |
| L3 封装 | L2 IC/元器件 | OSAT → IC设计公司 |
| L3 PCB/PCBA | L2 模组、L1 系统 | PCB厂 → 模组厂 / 整机厂 |
| L3 整装 | L1 硬件系统 | 代工厂 → 品牌厂商 |
| L2 IC/元器件 | L1 硬件系统 | 芯片商 / 模组商 → 整机厂 |
| L2 连接器/被动元件 | L1 系统、L3 PCBA | 连接器商 → 整机厂 / PCB组装厂 |
| L1 硬件系统 | 最终用户 | 设备商 → 运营商 / 企业 / 消费者 |

### 推断示例

| 用户输入 | 产品层级 | 客户层级 |
|---|---|---|
| 高速背板连接器 | L2 连接器 | L1 ICT设备/服务器 |
| PCB | L3 PCB/PCBA | L2 模组、L1 系统 |
| 导热硅脂 | L4 导热材料 | L3 封装/整装 |
| 车规MCU | L2 处理器 | L1 汽车及轨道交通 |
| SMT贴片 | L3 PCBA | L2 模组、L1 系统 |
| 光刻胶 | L4 功能材料 | L3 晶圆制造 |
| EDA软件 | L4 设计软件 | L2 IC设计、L3 PCB设计 |
