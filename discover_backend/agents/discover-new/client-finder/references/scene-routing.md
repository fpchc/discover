# 场景路由（场景 → 搜索词 → 来源 → 补搜条件 → 停止条件）

用户输入触发本技能时，按信号词判定场景，选对应搜索策略。所有场景最终都收敛到同一交付物（200~450 字信息卡）。

## 场景速查表

| 场景 | 识别信号 | 搜索词 | 数据来源 | 补搜条件 | 停止条件 |
|---|---|---|---|---|---|
| 单企调研 | 输入企业名称（「XX公司怎么样」） | `{企业名} 工商 主营 规模 官网` + `{企业名} 电话 邮箱 高管`（并发合并） | 企业画像（联网仅兜底） | 关键字段仍缺 | 字段达标或 1 轮补搜穷尽 |
| 核心拓客 | 「我卖/我们是做」+ 产品名 | `{产品}+{行业}` / `{产品}+{区域}` | 企业画像（联网仅兜底） | 候选池 <3 | 池≥3 或放宽后仍不足 |
| 定向搜索 | 行业/区域/规模 + 产品 | `{行业}+{区域}+{产品}` | 企业画像 | 候选池 <3 | 同上 |
| 竞品反推 | 「竞品/XX的客户/替代/切进去」 | `{竞品}+客户+供应链` | 联网 | 未发现目标客户 | 找到或穷尽 |
| 机会扫描 | 「趋势/热点/政策/国产替代」 | `{行业}+动态+机会` | 联网 | 无受益企业 | 找到或穷尽 |
| 区域聚焦 | 「XX地区/区域/产业带」 | `{区域}+{行业}+企业` | 企业画像 | 候选池 <3 | 池≥3 或放宽后仍不足 |
| 持续跟进 | 「上次/再找/刷新/重新/除了」 | 复用历史关键词 + 排除已推荐 | 企业画像（联网仅兜底） | 新线索不足 | 找到或穷尽 |

## 判定规则

1. 含企业名 → 单企调研；含竞品关键词 → 竞品反推；含「上次/再找/除了」 → 持续跟进。
2. 含产品/能力描述 → 核心拓客；再叠加行业/区域限制 → 定向搜索或区域聚焦。
3. 不含产品、仅行业/趋势/政策 → 机会扫描。
4. 模糊意图（「找客户」）→ 进入核心拓客流程（先需求澄清）。

## 通用约束

- 所有场景初筛均执行红线一票否决（失信 / 破产 / 吊销 / 严重违法）。
- 候选池不足 3 家 → 扩展关键词 / 放宽区域重搜一次；仍不足向用户说明。
- 补搜与停止条件遵循 `evidence-rules.md` 第四节。
- **单企调研走快车道（默认）**：跳过候选池、八维评分、Score Trace，只做「并发采集 → 补缺(≤1轮) → Final QA(2问) → 出卡」。
