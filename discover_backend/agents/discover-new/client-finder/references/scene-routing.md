# 场景路由

用户输入触发本技能时，只进入三类场景，最终都收敛到同一交付物：450~550 字信息卡；多企输入时每家各出一张，禁止合并成总体卡。

## 场景速查表

| 场景 | 识别信号 | 执行策略 | 停止条件 |
|---|---|---|---|
| 单企调研 | 输入企业名称 | 快车道：并发采集企业工商/主营/触达，缺核心字段补一轮 | 字段达标或补搜一轮穷尽 |
| 多企调研 | 输入多家企业名 | 每家独立走单企快车道，全部输出、不择优 | 每家均完成一张卡 |
| 候选池推荐 | 产品/能力 + 明确要求推荐 | 一轮召回 → top3 → 一次性评分 → 出卡 | 推荐 = 综合分第 1 |

## 判定顺序

1. 含企业名 → 单企或多企调研。
2. 明确要求「从候选池推荐」且输入为产品/能力 → 候选池推荐。
3. 其他模糊意图 → 按单企快车道处理，缺企业名再向用户澄清。

## 通用约束

- 所有场景均遵循 `evidence-rules.md` 的证据门槛与补搜封顶。
- 候选池场景红线一票否决（失信 / 破产 / 吊销 / 严重违法）。
- 单企 / 多企场景不做候选池、不做八维评分。
