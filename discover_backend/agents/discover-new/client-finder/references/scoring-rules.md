# 八维量化评分规则（V3 准确性优先版）

> **硬约束**：评分**必须**经 `scripts/score_calculator.py` 计算，**禁止** AI 直接给综合分。本文档提供逐维打分锚点，保留全部子维度；数据来源判定见 `evidence-rules.md`。

## 一、评分总览

```
综合分 = 采购规模×0.20 + 技术匹配×0.20 + 需求强度×0.15 + 采购时机×0.15
       + 竞争位置×0.10 + 触达可行性×0.10 + 决策复杂度×0.05 + 信用安全×0.05

排名 = 综合分降序
排除 = 信用安全 < 3.0 或 触发红线一票否决
```

评分流程：
1. 逐子维度打分，汇总为 8 个维度总分（0-10）；每维记录依据(basis) + 来源(source)。
2. 写临时 JSON → 调 `score_calculator`（必须经脚本）。
3. 数据缺失维度取中性分并标注「数据不充分·取中性分」。
4. 信用安全 < 3.0 或红线 → 直接排除。

## 二、维度 1：采购规模（权重 20%）

| 子维 | 分值 | 锚点 |
|---|---|---|
| 产品线相关性 | 5 | 主营直接使用目标产品品类，且有明确需求 |
| | 3 | 间接使用（经其下游或关联业务） |
| | 2 | 有关联但不直接 |
| | 0 | 无关联 |
| 企业体量 | 3 | 大型：注册资本≥1亿 或 参保≥1000 或 营收≥10亿 |
| | 2 | 中型：注册资本 1000万-1亿 或 参保 100-1000 |
| | 1 | 小型：注册资本<1000万 或 参保<100 |
| 增长趋势 | 2 | 有扩产 / 扩招 / 新产线信号 |
| | 1 | 经营平稳 |
| | 0 | 收缩（裁员 / 关厂 / 营收下滑>20%） |

## 三、维度 2：产品技术匹配（权重 20%）

| 子维 | 分值 | 锚点 |
|---|---|---|
| 层级上下游 | 4 | 直接下游（客户层级 = 自身层级 + 1） |
| | 3 | 直接下游但有自有产能（部分内制） |
| | 2 | 间接下游（+2） |
| | 1 | 同层级或微弱关联 |
| | 0 | 无关联 |
| 产品关键词命中 | 4 | 命中 ≥3 个目标品类关键词 |
| | 3 | 命中 2 个 |
| | 2 | 命中 1 个 |
| | 1 | 关键词仅出现在非主营业务 |
| | 0 | 无命中 |
| 技术参数对位 | 2 | 参数与自身产品明确对位 |
| | 1 | 推断对位（范围重合未确认） |
| | 0 | 参数不匹配 |

## 四、维度 3：需求强度（权重 15%）

| 子维 | 分值 | 锚点 |
|---|---|---|
| 直接采购信号 | 6 | 正在招标目标品类 |
| | 5 | 公开宣布扩产 / 新产线（3 个月内） |
| | 4 | 新品发布 / 产品线扩展 |
| | 3 | 大规模招聘相关研发 / 生产岗 |
| | 2 | 行业展会参展 / 技术论坛 |
| | 1 | 无直接信号但行业景气上行 |
| | 0 | 无任何信号 |
| 供应商切换信号 | 2 | 现有供应商重大质量 / 断供 |
| | 1 | 供应链多元化 / 第二供应商意向；或招标要求「新供应商 / 国产替代」 |
| | 0 | 无信息 |
| 行业景气度 | 2 | 景气上行（政策支持 / 需求旺盛 / 资本涌入） |
| | 1 | 平稳 |
| | 0 | 下行 |

## 五、维度 4：采购时机（权重 15%，含时间衰减）

| 信号类别 | 时间窗口 | 基础分 |
|---|---|---|
| 进行中招标 | 当前 | 10 |
| 融资 / 扩产公告 | 1 个月内 | 8 |
| 新品发布 | 1 个月内 | 7 |
| 展会 / 新品动态 | 3 个月内 | 6 |
| 招聘扩招 | 6 个月内 | 5 |
| 行业趋势信号 | 1 年内 | 4 |

规则：越近的信号基础分越高；超 6 个月的动态信号标注「可能已过时」。无时效信号取中性分。

## 六、维度 5：竞争位置（权重 10%）

| 子维 | 分值 | 锚点 |
|---|---|---|
| 竞品锁定程度 | 5 | 未发现明确供应商关系（无主之地） |
| | 4 | 有供应商但非独家 / 非战略 |
| | 3 | 有稳定供应商但非头部 |
| | 2 | 有头部供应商，但非战略 |
| | 1 | 与竞品战略合作 / 独家供应 |
| | 0 | 客户是竞品关联公司 / 子公司 |
| 替代窗口 | 3 | 主动寻源 / 招标标「新供应商」 |
| | 2 | 供应链多元化意向 |
| | 1 | 无信息 |
| | 0 | 明确「仅限现有供应商」 |
| 自身差异化匹配 | 2 | 有差异化优势且与需求匹配 |
| | 1 | 部分优势 |
| | 0 | 无明显优势 |

## 七、维度 6：触达可行性（权重 10%）

|---|---|---|
| 决策人可见度 | 5 | 姓名 + 职位 + 联系方式均可见 |
| | 4 | 姓名 + 职位 + 可直联 |
| | 3 | 姓名 + 职位（无联系方式） |
| | 2 | 仅职位（无姓名） |
| | 1 | 无决策人信息 |
| | 0 | 确定无法触达 |
| 触达渠道 | 3 | 有直接引荐路径 |
| | 2 | 决策人可直联（二度人脉内） |
| | 1 | 仅官网 / 总机冷触 |
| | 0 | 无法触达 |
| 联系难度 | 2 | 中小民企（决策链短） |
| | 1 | 大型民企（决策链中等） |
| | 0 | 外资 / 国企（决策链长） |

## 八、维度 7：决策复杂度（权重 5%，分高 = 易成交）

| 子维 | 分值 | 锚点 |
|---|---|---|
| 企业性质 | 5 | 中小民营 |
| | 4 | 中型民营 |
| | 3 | 大型民营 |
| | 2 | 外资 |

| | 1 | 混合 |
| | 0 | 强制招标（大量招标 / 最低价中标） |

## 九、维度 8：企业信用安全（权重 5%）

### 🚫 红线一票否决（任一触发直接排除，不再评分）

失信被执行人 / 破产清算或重整 / 经营状态吊销或注销 / 严重行政处罚（如吊销许可证）。

### 子维度

| 子维 | 分值 | 锚点 |
|---|---|---|
| 司法风险 | 4 | 无司法风险 |
| | 3 | 少量诉讼（<5 条，原告为主） |
| | 2 | 中等诉讼量（5-20）或小金额被告 |
| | 1 | 较多诉讼（>20）或大额被告 |
| | 0 | 有被执行记录（未达失信） |
| 经营合规 | 3 | 无异常经营、无行政处罚 |
| | 2 | 少量轻微行政处罚（1-2 条） |
| | 1 | 较多处罚或有经营异常 |
| | 0 | 严重违规 / 列入经营异常名录 |
| 财务健康 | 3 | 上市：营收正增长 + 净利正 + 毛利≥行业均值；非上市：纳税评级 A |
| | 2 | 上市：正常经营；非上市：纳税 B/C（非上市默认取此档） |
| | 1 | 上市：营收下滑>20% 或净利负；非上市：纳税 D / 无评级 |
| | 0 | 上市：ST 或连续 2 年亏损；非上市：税务非正常户 |

## 十、校准注意

1. 评分衡量「对该销售人员的综合匹配度」，不同产品 / 策略下同一企业得分不同。
2. 数据缺失维度取中间分并标「数据不充分·取中性分」。
3. 维度 4（采购时机）随时间衰减，3 个月后建议重评。
4. TOP 3 建议人工复查。
