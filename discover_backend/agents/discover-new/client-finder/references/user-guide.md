# EITIA 客户发现 — 使用手册（P1 数据受限版）

欢迎使用 EITIA 客户发现！本文档帮你快速上手：这个工具能做什么、怎么用、以及如何获得最好的结果。

## 1. 产品简介

**EITIA 客户发现**是专为电子信息产业链销售人员打造的智能拓客工具。它可以：

- 🎯 根据你的产品自动找到最匹配的潜在客户
- 📊 用 8 个维度给每家企业打分，帮你判断优先跟进谁
- 📋 生成包含企业画像、决策人、切入策略的专业报告
- 🔄 每次使用自动排除之前推荐过的企业，不重复

你只需告诉它「我卖什么」，它就能帮你找到「该卖给谁」。

## 2. 快速开始

### 示例 1：找客户（最常用）

**你说**：
> 我卖高速背板连接器，帮我找客户

**会发生什么**：
1. AI 会追问几个问题（用在什么场景？有什么优势？有标杆客户吗？有目标行业偏好吗？）
2. 你的回答越详细，结果越精准
3. 然后 AI 会自动搜索，生成一份含推荐企业的量化评分报告

### 示例 2：上次的客户联系完了，再找一批新的

**你说**：
> 上次推荐了 5 家高速背板连接器的客户，再帮我找 5 家新的，不要重复

**会发生什么**：
AI 会自动识别你之前搜过「高速背板连接器」，排除掉上次推荐的企业，从后备池或全新搜索中给你不一样的。

### 示例 3：快速评估一家公司

**你说**：
> 我在展会上见到 XX 公司，帮我评估一下是不是潜在客户？我们是做封装基板的

**会发生什么**：
AI 会快速搜索 XX 公司的公开信息，给你一份精简的评估报告，包含评分和跟进建议。

## 3. 我能做什么

| 场景 | 一句话说明 | 你可以这样说 |
|------|-----------|-------------|
| 🎯 **核心拓客** | 以你的产品为锚点，找下游客户 | "我卖XX，帮我找客户" |
| 🔍 **定向搜索** | 按行业/区域/规模等条件找客户 | "汽车电子行业里做域控制器的厂商" |
| 🔄 **持续跟进** | 第二次使用，自动去重、给新客户 | "上次那5家联系完了，再找5家新的" |
| ⚡ **单企评估** | 已知公司名，快速判断值不值得跟进 | "帮我评估一下XX公司" |
| 🏃 **竞品反推** | 从竞争对手出发，挖它的客户 | "安费诺的客户有哪些？" |
| 🔭 **机会扫描** | 看行业趋势，发现新机会 | "最近数据中心交换机行业有什么机会？" |
| 📍 **区域聚焦** | 按区域深耕 | "华东地区的汽车电子客户" |

**不需要填表格或选菜单**，用自然语言说出需求即可。输入越具体，结果越精准，但最少只需告诉「卖什么」。

## 4. 我会问你什么

AI 会问几个问题来精确理解需求，分三层：
- **必须回答的（1 个）**：你卖什么产品？
- **建议回答的（4 个）**：用在什么场景？有什么优势？有标杆客户吗？竞品是谁？（可以说「跳过」）
- **看情况的（6 个）**：目标行业？区域？客户规模？排除条件？急不急？要几家？（不回答用默认值）

## 5. 我能给你什么

生成的报告包含三层内容：

**第一层：全局概览** — 推荐排名表（含评分）、追客优先级矩阵、市场全景分析
**第二层：每家客户的深度画像** — 公司信息、产业链位置、匹配度分析、采购潜力、动态信号、风险评估、竞品分析
**第三层：行动指南** — 关键决策人、切入话术、触达策略

### 关于评分

8 个维度：采购规模 / 技术匹配 / 需求强度 / 采购时机 / 竞争位置 / 触达可行 / 决策复杂度 / 信用安全。综合分 = 各维度加权，由评分计算器统一算出。

### 优先级矩阵

```
紧迫度高 + 匹配度高 = 🔥 立即跟进（本周就联系）
匹配度高 + 紧迫度低 = ★ 长期培育（定期关注动态）
紧迫度高 + 匹配度低 = ⚡ 择机关注（等更好的时机）
```

## 6. 使用技巧

- **输入越具体，结果越精准**：从「找客户」→「我卖 112Gbps 高速背板连接器，用在数据中心交换机主板上，帮我找国内做数据中心交换机的厂商」
- **重复使用自动去重**：同一产品线索再次搜索自动排除已推荐企业
- **报告在哪找**：报告输出到当前会话的工作区 `output/` 目录，可下载 HTML 报告
- **后备池**：够格但不够好的候选进后备池，可随时「重新评估后备池」
- **找不到足够客户**：扩大行业范围、放宽区域限制、换关键词（如「背板连接器」→「高速连接器」）

## 7. 数据来源与局限性（P1 数据受限版）

P1 数据源仅 **公开搜索（alibaba_search）**。以下专有数据源属后续版本恢复，P1 缺失：
- 企业工商数据库（天眼查 / 企查查）：P1 无工商登记/股东/风险扫描批量数据
- 职场人脉平台（脉脉）：P1 无决策人人脉直联
- 上市公司财务（东方财富）：P1 无结构化财务

**因此 P1 报告会：**
- 标注「数据来源受限版本」
- 数据不充分的维度取中性分并标注
- 无法识别的决策人标注「公开社交平台未能识别到决策人」
- 所有关键结论标注来源或「推断」

## 8. 常见问题

- **为什么有些客户评分高但我觉得不合适？** 评分基于可获取的公开数据，无法完全反映业务偏好，是辅助判断工具。
- **为什么第二次还出现之前推荐过的企业？** 两次输入产品关键词差异较大时可能未识别为同一线索，可提供具体输入改进匹配。
- **搜索到的企业数量太少怎么办？** 放宽条件：扩大行业、取消区域限制、换更通用的关键词。
- **报告可以分享吗？** 可以。HTML 报告可直接分享，注意报告可能含公开个人信息，分享前确认符合公司规范。
- **非电子信息产业链的企业能用吗？** 本工具专为电子信息产业链设计，EITIA 四层架构与评分体系基于电子行业，其他行业不准确。
