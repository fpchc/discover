# 信息卡排版规范（输出重点分明红线）

> 适用场景：输出 200~450 字企业信息卡时。本文件定义信息卡的**排版结构**与**加粗要点**规则，是「重点分明」的唯一权威依据；`AGENT.md` 输出契约的措辞与本文件冲突时，以本文件为准。
> 目标：让销售 10 秒内扫到「这是什么公司、多大规模、有没有风险、为什么值得跟」。

## 1. 三段式结构（强制）

每张信息卡必须按以下顺序组织，缺一段即视为排版不合格：

1. **定位句**（第 1 句，必须加粗开头关键词）：一句话点明 行业 + 主营业务 + 是否上市 + 体量量级。例：`**电子元器件分销商｜深圳宝安｜2021年成立｜未上市**`。
2. **关键事实段**：工商 / 规模 / 触达 / 风险等硬信息。**逐条成行，每条以加粗小标签开头**（如 `**注册资本**`、`**规模**`、`**联系**`），一行为一小条，禁止把多条塞进一个长句。
3. **切入价值段**（结尾 1-2 句）：给客户群 / 应用领域 / 可切入机会；风险点作为「注意」单独成行收尾。

## 2. 加粗要点规则（强制）

- **大数字必加粗**：注册资本、成立年份、人员/参保规模、专利数、营收量级。
- **风险必加粗并前置或单列**：失信 / 司法案件 / 吊销 / 严重违法等，写成 `**注意**：…` 单独一行，不得藏在长段末尾。
- **触达信息单列**：电话 / 邮箱 / 官网逐项用小标签列出（`**电话**`、`**邮箱**`、`**官网**`），避免挤在一行。
- **标签统一**：小标签固定用 `**注册资本**`、`**成立**`、`**地址**`、`**规模**`、`**主营**`、`**联系**`（或 `**电话/邮箱/官网**`）、`**注意**`；标签内不再堆形容词。

## 3. 禁例（一票否决）

- 整段纯散文、无任何加粗与分行，硬信息埋在长句里（视为「一团乱」）。
- 用 `|`、`｜`、`—` 做分隔符的机械串行模版（违反 AGENT.md「严禁机械套用固定模版」）。
- 一段里出现超过 2 个未加粗的字段罗列（如「电话xxx邮箱xxx官网xxx」连写）。

## 4. 字数与扫读

- 200~450 字（含标点）；标签与加粗不重复计内容。
- 行文仍自然：定位句可带一句行业解释，价值段用销售语言，不写成流水账。

## 5. 正反例对照

**反面例（一团乱，禁）**：

> 深圳市XX科技有限公司——深圳宝安区电子元器件批发商，注册资本1000万（实缴100万），2021年成立，未上市。公司主营电子产品、通讯设备、计算机硬件及电子元器件的技术开发与销售，兼营计算机软硬件及进出口业务。注册地址位于宝安区XX街道XX电子工业区，员工不足50人（参保35人），属小微企业。联系电话1XX-XXXX-XXXX，邮箱xx@example.com，官网https://www.example.com。作为电子元器件分销渠道商，其PCB需求可能来自下游客户配套采购或自有品牌产品的电路板代工，适合以标准品批量供应切入。

**正面例（达标）**：

> **电子元器件分销商｜深圳宝安｜未上市**，2021年成立，注册资本1000万（实缴100万），员工不足50人（参保35人），属小微企业。
>
> **主营**：电子产品、通讯设备、计算机硬件及电子元器件的技术开发与销售，兼营计算机软硬件及进出口。
> **地址**：宝安区XX街道XX电子工业区。
> **电话**：1XX-XXXX-XXXX
> **邮箱**：xx@example.com
> **官网**：https://www.example.com
>
> **切入**：作为电子元器件分销渠道商，PCB需求来自下游配套采购或自有品牌电路板代工，适合以标准品批量供应切入。

（正面例中的数字、标签均为加粗或单列，风险若有则另起 `**注意**` 行；示例企业为脱敏占位，非真实数据。）
