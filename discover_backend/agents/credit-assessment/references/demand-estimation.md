# 客户账期评估 — PCB 需求总体量摸排

> 本文件定义 PCB 年采购盘子的估算方法。盘子 P 是授信额度的直接输入（额度 = P/12 × 账期月数 × 授信系数），估算准确性直接影响额度合理性。

---

## 一、核心原则

1. **给区间不给单点**：盘子估算本质是推测，必须给敏感性区间，禁止单点估值
2. **参数标来源**：每个参数要么来自年报/招股书（第一手），要么显式标注"行业经验假设"
3. **三方法交叉**：成本占比法（主推）+ 供应商采购额（交叉）+ 可比三角（参照），互相印证

---

## 二、方法 A · 成本占比法（主推）

### 公式

```
PCB年盘子 ≈ 直接材料额 × PCB占直接材料比
直接材料额 = 营收 × 营业成本率 × 直接材料占比
```

### 参数来源

| 参数 | 来源 | 可靠性 |
|------|------|--------|
| 营收 | 年报/季报 | ★★★★★ 精确 |
| 营业成本率（=1-毛利率）| 年报 | ★★★★★ 精确 |
| 直接材料占比 | 年报营业成本构成 | ★★★★★ 精确 |
| PCB 占直接材料比 | 招股书原材料构成表（第一手）| ★★★★ 需校准 |

### 关键：PCB 占比的可靠来源

**最可靠来源是标的公司 IPO 招股说明书的"原材料构成表"**——披露各类原材料采购占比，PCB 裸板通常落在"其他类"或未单列的小品类中，据此可锁定上限。

**案例（凯格精机）**：招股书披露原材料分 5 大类——非标加工件 37.7% / 光电元件 38% / 机械配件 16.7% / 气动 5.2% / **其他类 2.4%**。PCB 落在"其他类"，故 PCB 占直接材料上限 ≤ 2.4%。

**交叉验证**：同行业可比公司招股书（如 SMT 设备同行劲拓股份）前 20 项原材料均无 PCB 单列，印证 PCB 占比远低于机械件/控制件。

### 估算流程

```
1. 采集营收 + 营业成本率 + 直接材料占比（年报，精确值）
2. 采集 PCB 占直接材料比（招股书原材料构成表，锁定上限）
3. 若无招股书：用可比公司招股书参照，标"行业经验假设"
4. 计算区间：P_low = 直接材料 × 占比下限；P_high = 直接材料 × 占比上限
5. 取中值 P_mid 作为额度测算基准
```

---

## 三、方法 B · 供应商采购额（交叉）

### 公式

```
PCB年盘子下限 ≈ 前五大供应商中 PCB 厂商采购额之和
```

### 说明

年报"前五大供应商"披露合计采购额和占比。若能识别其中 PCB 厂商（深南电路/景旺电子/崇达技术等），其采购额之和是盘子下限。

### 局限

年报通常**不披露供应商具体名称**，无法确认 PCB 厂商是否在前五，仅作方向参考，不能作为主推方法。

---

## 四、方法 C · 可比三角（参照）

### 公式

```
同业可比公司 BOM 中 PCB 占比作参照
```

### 说明

选取同行业（如 SMT 设备、精密自动化装备）可比公司，其招股书/年报的原材料构成中 PCB 占比，作为标的公司 PCB 占比的参照区间。

### 局限

不同公司产品结构差异大，可比公司 PCB 占比只能作方向参考，不能直接套用。

## 六、落地建议

1. 报告中**必须展示**敏感性区间，禁止只给中值
2. PCB 占比参数标注来源（招股书页码 / 可比公司 / 行业经验），非第一手数据必须标"假设"
3. 接触客户后通过采购部门确认 PCB 供应商名单及年采购额，将估算中值校准为实际值
4. 客户营收高增长时，注明盘子有上行空间
