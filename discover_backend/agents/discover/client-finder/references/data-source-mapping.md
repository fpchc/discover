# 数据源映射（数据能力版）

> 数据源由平台装配的数据能力提供。**优先级：企业专有数据能力（天眼查等工商/风险数据）> 联网搜索（公开信息，仅兜底）> AI 推断**。
>
> 企业专有数据能力覆盖工商、风险字段时，不再查联网搜索获取同一字段；联网搜索仅用于企业专有能力无法覆盖的字段（招标信号、行业动态、竞品格局等），以及企业专有能力全部不可用时的降级兜底。可用工具以运行时目录为准，不假定工具名。具体提供方与可用性由平台配置，本技能不点名提供方、不写降级逻辑。
>
> 每个「维度」的取值方式是：**数据能力采集 + 推断**，凡信息缺失一律在报告/对话中标注「数据不充分」或「推断」，不得编造。

## 一、八维评分数据获取对照

| # | 维度 | 数据能力获取方式 | 充足信号 | 受限标注 |
|---|------|----------------|---------|-------------|
| ① | 采购规模 | 企业画像能力（enterprise_business）查规模（注册资本/人数/营收新闻）+ 招聘/扩产/招标线索推断采购量 | 注册资本 + 扩产新闻 + 招标 | 无财务数据 → 按规模档位估算，标「推断」 |
| ② | 技术匹配 | 企业画像能力（enterprise_business）查主营/产品线/专利；企业画像无法覆盖时再以联网搜索（web_search）对照层级与产品关键词 | 主营含目标品类词 + 技术参数新闻 | 无产品信息 → 标「数据不充分·取中性分」 |
| ③ | 需求强度 | 联网搜索（web_search）招标/扩产/新品发布/招聘信号（仅企业画像不覆盖此字段） | 近 3 个月信号 ≥1 条 | 无信号 → 标「未发现直接信号」 |
| ④ | 采购时机 | 同③信号的时间衰减计算（见 scoring-rules）（仅企业画像不覆盖此字段） | 进行中招标 / 近期扩产 | 无时效信号 → 取中性 |
| ⑤ | 竞争位置 | 联网搜索（web_search）「企业名 + 供应商/竞品」判断现有供应商格局（仅企业画像不覆盖此字段） | 明确报道 | 无信息 → 标「无公开信息」 |
| ⑥ | 触达可行 | 企业画像能力（enterprise_business）查决策人（董监高）；企业画像无法覆盖时再以联网搜索（web_search）公开报道补充 | 姓名 + 职位 | 无法识别 → 标「公开社交平台未能识别到决策人」 |
| ⑦ | 决策复杂度 | 企业画像能力（enterprise_business）查企业性质 + 规模推断 | 企业类型 + 参保人数 | 缺失 → 推断并标注 |
| ⑧ | 信用安全 | 企业风险能力（enterprise_risk）查失信/破产/吊销/严重违法 | 无红线记录 | 未发现 ≠ 无风险，报告注明「以公开信息为准」 |

## 二、联网搜索通道（web_search 能力，仅兜底）

> 联网搜索仅在企业专有数据能力不可用或无法覆盖以下字段时启用。若企业画像/风险能力已成功采集数据，不再重复查联网搜索。

对每个通道用关键词组合并发搜索，多通道互补：

| 通道 | 搜索模式 | 用途 |
|------|---------|------|
| 行业+区域 | `{产品} {行业}` / `{行业} {区域} 企业 排名` | 候选池来源 |
| 企业精确 | `{企业名} 主营 规模` | 深挖核实 |
| 竞品反推 | `{竞品} 客户 供应链` | 竞品客户逆向 |
| 招标信号 | `{产品品类} 招标 采购` | 需求强度 / 采购时机 |
| 决策人 | `{企业名} 董事长 总经理 高管` | 触达可行 |
| 风险 | `{企业名} 失信 破产 处罚` | 信用安全 |

**并发要求**：应尽可能批量并发采集，覆盖多维度；无硬性最低调用数。单源失败不中断流程，换关键词组合重搜并标注。

## 三、事实断言交叉验证

| 断言类型 | 最少来源 | 说明 |
|---------|:---:|------|
| 技术来源/代码继承 | 2 个独立源 | 官网 + 新闻双重确认 |
| 市场份额/排名 | 2 个独立源 | 研报 + 行业报告 |
| 客户-供应商关系 | 2 个独立源 | 工商数据 + 新闻 |
| 竞品能力对比 | 2 个独立源 | 参数对比 + 评测 |

单源断言必须标注信息来源（如「据 XX 官网声称」）；推断性结论用「推断 / 可能 / 估计」。

## 四、数据能力说明

数据能力由平台注册表装配（企业画像 / 企业风险 / 财务数据 / 联网搜索），提供方与可用性由平台配置；可用工具以运行时目录为准，不假定工具名。各维度表格即按可用能力采集，缺失维度的数据按上文「受限标注」列处理。

**数据优先级**：同一字段同时有多个数据源时，以企业专有数据能力（enterprise_business / enterprise_risk）的数据为准（L0 官方工商登记），联网搜索仅作为兜底补充，不与企业数据冲突。
