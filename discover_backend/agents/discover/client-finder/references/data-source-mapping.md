# 数据源调用映射表（P1 数据受限版）

> **P1 数据源策略**：仅 `alibaba_search`（公开搜索）。原双引擎（天眼查 tyc-mcp + 企查查 qcc-mcp）及脉脉 / 东方财富等专有数据源属 P2 恢复路径，恢复时增量加回本节。
>
> 每个「维度」的取值方式是：**搜索 + 推断**，凡信息缺失一律在报告/对话中标注「数据不充分」或「推断」，不得编造。

---

## 一、八维评分数据获取对照（P1）

| # | 维度 | P1 数据获取方式 | 充足信号 | 受限降级标注 |
|---|------|----------------|---------|-------------|
| ① | 采购规模 | 搜索企业规模（注册资本/人数/营收新闻）+ 招聘/扩产/招标线索推断采购量 | 注册资本 + 扩产新闻 + 招标 | 无财务数据 → 按规模档位估算，标「推断」 |
| ② | 技术匹配 | 搜索企业主营 / 产品线 / 专利新闻，对照 EITIA 层级与产品关键词 | 主营含目标品类词 + 技术参数新闻 | 无产品信息 → 标「数据不充分·取中性分」 |
| ③ | 需求强度 | 搜索招标 / 扩产 / 新品发布 / 招聘信号 | 近 3 个月信号 ≥1 条 | 无信号 → 标「未发现直接信号」 |
| ④ | 采购时机 | 同③信号的时间衰减计算（见 scoring-rules） | 进行中招标 / 近期扩产 | 无时效信号 → 取中性 |
| ⑤ | 竞争位置 | 搜索「企业名 + 供应商/竞品」判断现有供应商格局 | 明确报道 | 无信息 → 标「无公开信息」 |
| ⑥ | 触达可行 | 搜索决策人（工商董监高 / 公开报道职位） | 姓名 + 职位 | 无法识别 → 标「公开社交平台未能识别到决策人」 |
| ⑦ | 决策复杂度 | 企业性质 + 规模推断 | 企业类型 + 参保人数 | 缺失 → 推断并标注 |
| ⑧ | 信用安全 | 搜索失信 / 破产 / 吊销 / 严重违法 | 无红线记录 | 未发现 ≠ 无风险，报告注明「以公开信息为准」 |

## 二、搜索通道（P1 仅 alibaba_search）

对每个通道用关键词组合并发搜索，多通道互补：

| 通道 | 搜索模式 | 用途 |
|------|---------|------|
| 行业+区域 | `{产品} {行业}` / `{行业} {区域} 企业 排名` | 候选池来源 |
| 企业精确 | `{企业名} 主营 规模` | 深挖核实 |
| 竞品反推 | `{竞品} 客户 供应链` | 竞品客户逆向 |
| 招标信号 | `{产品品类} 招标 采购` | 需求强度 / 采购时机 |
| 决策人 | `{企业名} 董事长 总经理 高管` | 触达可行 |
| 风险 | `{企业名} 失信 破产 处罚` | 信用安全 |

**并发要求**：应尽可能批量并发搜索，覆盖多维度；P1 无硬性最低调用数。单源失败不中断流程，降级为其他关键词组合并标注。

## 三、事实断言交叉验证（P1）

| 断言类型 | 最少来源 | 说明 |
|---------|:---:|------|
| 技术来源/代码继承 | 2 个独立源 | 官网 + 新闻双重确认 |
| 市场份额/排名 | 2 个独立源 | 研报 + 行业报告 |
| 客户-供应商关系 | 2 个独立源 | 工商数据 + 新闻 |
| 竞品能力对比 | 2 个独立源 | 参数对比 + 评测 |

单源断言必须标注信息来源（如「据 XX 官网声称」）；推断性结论用「推断 / 可能 / 估计」。
