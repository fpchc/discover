# 八维量化评分规则（V5 更新）

本文档是评分规则的完整版，在阶段 2.4（八维量化评分）时加载。SKILL.md 正文仅保留各维度概述和权重，本文档提供详细的打分映射、时间衰减系数和边界条件。

## 零、评分流程（强制使用计算器）

> ⚠️ **硬约束**：评分**必须**通过 `scripts/score_calculator.py` 计算，**禁止** AI 直接给出分数。

评分流程：
1. **逐子维度打分**：按本文档 §二~§九 对每客户的每个子维度打分，记录原始数据和来源
2. **汇总维度分**：将子维度分数汇总为 8 个维度总分（0-10）
3. **调用计算器**：`echo '{...}' | python scripts/score_calculator.py`
4. **输出映射**：将计算器输出的 composite_score 和各维度分写回 JSON 的 `c.match_subscore_N` 结构体
5. **交叉验证**：若计算器输出与手动估分偏差 > 0.5，以计算器为准

---

## 一总览

```
综合分 = 采购规模×0.20 + 技术匹配×0.20 + 需求强度×0.15 + 采购时机×0.15
         + 竞争位置×0.10 + 触达可行性×0.10 + 决策复杂度×0.05 + 信用安全×0.05

排名 = 综合分降序
排除 = 信用安全 < 3.0 或 触发红线一票否决
后备池 = 综合分 ≥ 4.0 但未进入 TOP N
```

## 二维度 1：采购规模估算（权重 20%）

**目标**：估算该客户对目标产品的潜在采购规模和增长趋势。

### 子维度 1.1：产品线相关性（0-5 分）

| 分值 | 判定标准 | 数据来源 |
|:---:|---------|----------|
| 5 | 客户主营业务直接使用目标产品品类，且有明确需求 | 天眼查主营 + 官网产品页 + 博查搜索 |
| 3 | 客户间接使用目标产品（通过其下游或关联业务） | 天眼查主营 + 层级推断 |
| 2 | 客户业务与目标产品品类有一定关联但不直接 | 博查搜索 + AI 推断 |
| 0 | 看不出关联 | — |

### 子维度 1.2：企业体量（0-3 分）

| 分值 | 判定标准 | 数据来源 |
|:---:|---------|----------|
| 3 | 大型企业（注册资本 ≥ 1亿 或 参保人数 ≥ 1000 或 营收 ≥ 10亿） | 天眼查 basic_profile + 东方财富（上市公司） |
| 2 | 中型企业（注册资本 1000万-1亿 或 参保人数 100-1000） | 同上 |
| 1 | 小型企业（注册资本 < 1000万 或 参保人数 < 100） | 同上 |

### 子维度 1.3：增长趋势（0-2 分）

| 分值 | 判定标准 | 数据来源 |
|:---:|---------|----------|
| 2 | 有明确扩产/扩招/新产线信号 | 天眼查 recruitment_info + 新闻动态 |
| 1 | 经营平稳，无明显增减 | 东方财富财务趋势 |
| 0 | 有收缩信号（裁员/关厂/营收下滑 >20%） | 新闻+财务 |

## 三维度 2：产品技术匹配度（权重 20%）

**目标**：评估目标客户的技术需求与自身产品的契合程度。

### 子维度 2.1：层级上下游关系（0-4 分）

| 分值 | 判定标准 |
|:---:|---------|
| 4 | 直接下游（客户所在层级 = 自身层级 + 1） |
| 3 | 直接下游但客户有自有产能（部分内制） |
| 2 | 间接下游（客户所在层级 = 自身层级 + 2） |
| 1 | 同层级或有微弱关联 |
| 0 | 无关联 |

### 子维度 2.2：产品关键词命中（0-4 分）

| 分值 | 判定标准 |
|:---:|---------|
| 4 | 命中 ≥ 3 个目标产品关键词（如连接器+高速+背板） |
| 3 | 命中 2 个关键词 |
| 2 | 命中 1 个关键词 |
| 1 | 关键词出现在非主营业务中 |
| 0 | 无命中 |

数据来源：客户官网（TinyFish/Tavily 提取）+ 天眼查经营范围 + 招聘岗位技能要求 + 专利信息。

### 子维度 2.3：技术参数对位（0-2 分）

| 分值 | 判定标准 | 数据来源 |
|:---:|---------|----------|
| 2 | 客户产品技术参数与自身产品明确对位（如：客户交换机支持 400G，自身连接器速率匹配） | 天眼查专利 + 招聘技能要求 + Tavily 研报 |
| 1 | 推断对位（参数范围重合但未明确确认） | AI 推断 |
| 0 | 参数不匹配（如自身低速连接器 vs 客户需要高速） | — |

| 分值 | 判定标准 | 数据来源 |

| 4 | 有新品发布/产品线扩展 | 博查新闻 + 官网 |
| 3 | 正在大规模招聘相关研发/生产岗位 | 天眼查 recruitment_info |
| 2 | 行业展会参展/技术论坛参与 | 博查搜索 |
| 1 | 无直接信号但行业景气上行 | 东方财富研报 |
| 0 | 无任何信号 | — |

### 子维度 3.2：供应商切换信号（0-2 分）

| 分值 | 判定标准 | 数据来源 |
|:---:|---------|----------|
| 2 | 公开报道现有供应商出现重大质量问题/断供 | 博查 + Tavily |

### 子维度 3.3：行业景气度（0-2 分）

| 分值 | 判定标准 | 数据来源 |
|:---:|---------|----------|
| 2 | 客户所在行业处于景气上行周期（政策支持/需求旺盛/资本涌入） | 东方财富研报 + mx_macro_data + 博查 |
| 1 | 平稳 | 同上 |
| 0 | 下行周期 | 同上 |

## 五维度 4：采购时机（权重 15%，含时间衰减）

**目标**：评估联系客户的最佳时间窗口。

### 信号类别与时间衰减

| 信号类别 | 时间窗口 | 衰减系数 | 基础分 | 数据来源 |
|----------|:--:|:--:|:--:|----------|
| 正在进行中的招标 | 当前 | ×1.0 | 10 | 天眼查招标 + AnySearch |
| 融资/扩产公告 | 1 个月内 | ×1.0 | 8 | 天眼查 news_sentiment + 博查 |
| 新品发布 | 1 个月内 | ×1.0 | 7 | 博查新闻 |
| 行业展会参与/新品动态 | 3 个月内 | ×0.7 | 6 | 博查 + Tavily |
| 招聘扩招 | 6 个月内 | ×0.5 | 5 | 天眼查 recruitment_info |
| 行业趋势信号 | 1 年内 | ×0.3 | 4 | 东方财富研报 + Tavily |

### 最终时机分

```
时机分 = Σ(每个信号的基础分 × 衰减系数) / 最大可能分 × 10
最大可能分 = 10×1.0 + 8×1.0 + 7×1.0 + 6×0.7 + 5×0.5 + 4×0.3 = 32.9

最终时机分 = 时机分（0-10），映射到 0-10 区间
```

## 六维度 5：竞争位置（权重 10%）

**目标**：评估自身在竞品格局中的相对位置。

### 子维度 5.1：竞品锁定程度（反向，0-5 分）

| 分值 | 判定标准 | 数据来源 |
|:---:|---------|----------|
| 5 | 未发现明确供应商关系，属于"无主之地" | 博查 + Tavily 搜索"XX公司 供应商"无果 |
| 4 | 有供应商但非独家/非战略合作 | 同上 |
| 3 | 有稳定供应商但非头部（中小供应商） | Tavily 研报 + 博查 |
| 2 | 有头部供应商，但非战略合作 | 同上 |
| 1 | 与竞品有战略合作关系/独家供应 | 公开报道 |
| 0 | 客户是竞品的关联公司/子公司 | 天眼查关联企业 |

### 子维度 5.2：替代窗口（0-3 分）

| 分值 | 判定标准 |
|:---:|---------|
| 3 | 客户主动寻源/公开招标中标注"新供应商" |
| 2 | 有供应链多元化意向（年报/公开言论） |
| 1 | 无信息 |
| 0 | 明确表示"仅限现有供应商"或"不接受新供应商" |

### 子维度 5.3：自身差异化优势匹配（0-2 分）

| 分值 | 判定标准 |
|:---:|---------|
| 2 | 自身产品有明显差异化优势（性能/价格/交期/国产替代）且与客户需求匹配 |
| 1 | 部分优势 |
| 0 | 无明显优势 |

## 九维度 8：企业信用安全（权重 5%）

**目标**：确保推荐的客户信用可靠，规避坏账和合作风险。

### 🚫 红线一票否决项

以下任一条件触发，**直接排除**，不再进入评分：

| 条件 | 数据来源 |
|------|----------|
| 失信被执行人（老赖） | 天眼查 credit_evaluation |
| 破产清算/破产重整 | 天眼查 risk_overview |
| 经营状态为"吊销"或"注销" | 天眼查 basic_profile |
| 存在严重行政处罚（如吊销许可证） | 天眼查 risk_overview |

### 子维度 8.1：司法风险（0-4 分）

| 分值 | 判定标准 | 数据来源 |
|:---:|---------|----------|
| 4 | 无任何司法风险 | 天眼查 risk_overview |
| 3 | 少量诉讼（< 5 条，且为原告为主） | 同上 |
| 2 | 中等诉讼量（5-20 条）或作为被告但金额小 | 同上 |
| 1 | 较多诉讼（> 20 条）或有大额被告案件 | 同上 |
| 0 | 有被执行记录（即使未达失信） | 同上 |

### 子维度 8.2：经营合规（0-3 分）

| 分值 | 判定标准 | 数据来源 |
|:---:|---------|----------|
| 3 | 无异常经营、无行政处罚 | 天眼查 basic_profile + risk_overview |
| 2 | 少量行政处罚（1-2 条，轻微） | 同上 |
| 1 | 较多行政处罚或有经营异常记录 | 同上 |
| 0 | 严重违规/列入经营异常名录 | 同上 |

### 子维度 8.3：财务健康（0-3 分）

**上市公司**（数据来源：东方财富）：

| 分值 | 判定标准 |
|:---:|---------|
| 3 | 营收正增长 + 净利润为正 + 毛利率 ≥ 行业均值 |
| 2 | 正常经营（营收稳定/微降、净利润为正） |
| 1 | 营收显著下滑（>20%）或净利润为负 |
| 0 | ST 标识或连续 2 年亏损 |

**非上市公司**（数据来源：天眼查）：

| 分值 | 判定标准 |
|:---:|---------|
| 3 | 纳税评级 A 级 |
| 2 | 纳税评级 B/C 级 |
| 1 | 纳税评级 D 级或无评级 |
| 0 | 税务非正常户 |

**注**：非上市公司的财务信息通常不公开，纳税评级是唯一可公开获取的财务健康信号。非上市公司默认财务健康分为 2 分（中性）。

## 十评分计算示例

### 示例：锐捷网络（产品：高速背板连接器）

| 维度 | 原始分 | 权重 | 加权分 | 说明 |
|------|:-----:|:---:|:-----:|------|
| 1. 采购规模 | 8.0 | 20% | 1.60 | 大型网络设备商，直接使用连接器 |
| 2. 技术匹配 | 9.0 | 20% | 1.80 | 直接下游、高速产品、参数对位 |
| 3. 需求强度 | 7.0 | 15% | 1.05 | 数据中心交换机扩产、有招标 |
| 4. 采购时机 | 7.5 | 15% | 1.13 | 近期有招标、扩产信号 |
| 5. 竞争位置 | 6.0 | 10% | 0.60 | 已有供应商但非独占 |
| 6. 触达可行性 | 8.0 | 10% | 0.80 | 决策人可见 + 脉脉可联 |
| 7. 决策复杂度 | 4.0 | 5% | 0.20 | 大型民企，招标采购 |
| 8. 信用安全 | 9.0 | 5% | 0.45 | 上市公司，信誉良好 |
| **综合** | — | — | **7.63** | ✅ 推荐 |

## 十一校准注意事项

1. **评分≠绝对好坏**：8 维评分衡量的是"对该销售人员的综合匹配度"，不同产品、不同销售策略会导致同一企业在不同场景下得分不同。
2. **数据不完备时的处理**：如果某维度数据缺失（如非上市公司的财务数据），该子维度取中间分（如 3 分量表的 2 分），并在报告中标注"数据不完整"。
3. **时间敏感性**：维度 4（采购时机）的评分随时间衰减，建议同一客户在 3 个月后重新评估。
4. **人工复验建议**：评分是辅助决策工具，TOP 3 客户建议人工复查确认。
