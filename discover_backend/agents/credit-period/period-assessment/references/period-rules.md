# 账期评估 — 账期档位与信用额度（P1 版）

> 本文件定义「建议账期」与「建议额度」的计算规则。计算由 `scripts/period_calculator.py` 强制执行，AI 不得手算。
> P1 需求盘子估算给**区间不给单点**，软参数必须标注「假设」。

---

## 一、账期档位（叠加 AR 硬约束）

综合授信分 CS 与财务健康分 F 共同决定基础档位：

| 条件 | 基础档位 |
|------|------|
| CS≥8.5 且 F≥8 | 90 天 |
| CS≥7 且 F≥6.5 | 60 天 |
| CS≥5.5 | 45 天 |
| CS≥4 | 30 天 |
| CS<4 | 现款现货/30% 预付 |

### 1.1 AR 硬约束（核心红线之外的硬规则）

```
建议账期 = min(基础档位, 客户自身应收周转天数 AR)
```

**原理**：客户自己向别人收款都不到这个周期，我们垫资必超其回款节奏，账期越长坏账敞口越大。

示例：凯格精机 AR=44 天、CS=9.5 → 基础档位 90 天 → 建议账期 = min(90, 44) = **44 天**。

### 1.2 红线阻断

任一红线触发 → 建议账期 = 0，标「现款现货/30%预付」，授信额度 = 0。

## 二、信用额度计算

```
M = (年盘子 P / 12) × 账期月数 × 授信系数
```

- 月盘子 = 客户年采购盘子 / 12
- 账期月数 = 建议账期天数 / 30
- 授信系数：S=1.0 / A=0.85 / B=0.7 / C=0.4 / D=0

示例：P=480 万、账期 44 天（1.47 月）、S 级系数 1.0 → M = (480/12) × 1.47 × 1.0 = **59 万**。

## 三、需求盘子估算（P1 三方法，给区间不给单点）

「年盘子 P」是额度的分母（额度 = P/12 × 账期月数 × 授信系数），估算准确性直接影响额度合理性。

### 3.1 核心原则

1. **给区间不给单点**：盘子估算本质是推测，必须给敏感性区间，禁止单点估值
2. **参数标来源**：每个参数要么来自公开第一手（财报/招股书/公告），要么显式标注「行业经验假设」
3. **三方法交叉**：营收比例法（主推）+ 产能/项目信号法（交叉）+ 对标法（参照），互相印证

### 3.2 方法 1 · 营收比例法（有营收可得时优先）

```
P ≈ 客户年度营收 × 对应品类采购占比
```

| 参数 | 来源 | 可靠性 |
|------|------|--------|
| 客户年度营收 | 上市：公开财报；非上市：规模档位估算（员工数×人均产值） | ★★★★~★★★★★ |
| 对应品类采购占比 | 公开披露（招股书/年报供应商构成）→ 精确；否则行业基准区间 | ★★★★ 需校准 |

- 上市客户营收从公开财报取，精确；非上市标「假设」
- 采购占比有公开披露用之；否则用行业基准区间并标「假设」
- 例：客户营收 3 亿、品类采购占比 1.5%（招股书原材料构成表锁定上限）→ P ≈ 30000 × 1.5% = **450 万**

### 3.3 方法 2 · 产能/项目信号法

```
P ≈ 扩产投资额 × 品类占比系数
```

- 扩产/招标/新建项目：从公开新闻/招标信息采集，带日期，超 6 个月标「可能已过时」
- 占比系数无披露时标「假设」，仅作方向参考，不作主推

### 3.4 方法 3 · 对标法

```
P ≈ 同行业同规模可比公司采购额 × 调整系数
```

- 选取同行业同规模可比公司，其公开披露的采购额/占比作参照区间
- 不同公司产品结构差异大，只能作方向参考，不能直接套用；对标公司须标注名称与依据

### 3.5 敏感性分析模板

| 品类采购占比 | 年盘子 P | 对应月盘子 | 对应账期额度 |
|---|---|---|---|
| 占比下限（保守） | ... | ... | ... |
| 占比中值 | ... | ... | ... |
| 占比上限（乐观） | ... | ... | ... |
| 公开披露硬上限 | ... | ... | ... |

### 3.6 三方法结论与落地建议

- 取三者交叉区间 `[P_low, P_high]`，取中值代入额度公式
- 报告给出「额度区间」而非单点：`M_low` ~ `M_high`
- 任一方法不可行 → 只列可行方法并标「数据受限」，绝不编造盘子
- 报告中**必须展示敏感性区间**，禁止只给中值；非第一手参数一律标「假设」
- 接触客户后通过采购部门确认品类供应商名单及年采购额，将估算中值校准为实际值
- 客户营收高增长时，注明盘子有上行空间

## 四、监控与滚动评估

- **监控指标**：回款逾期率、账期超限笔数、客户财报/风险信号变化
- **退出触发**：出现红线项、连续 2 月逾期、涉诉为被告金额超额度 30%
- **滚动评估**：每季度按最新数据重评一次；额度上修须重新走评分
